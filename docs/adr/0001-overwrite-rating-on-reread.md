# 재독하면 이전 평점과 감상평을 덮어쓴다

책 하나는 독서 상태, 평점, 감상평을 하나씩만 가진다. 다시 읽고 다 읽음으로 바꾸면 이전 평점과 감상평은 새 값으로 덮어써져 사라진다. 회차별 독서 기록(책과 독서를 분리하는 구조)도 검토했지만, 간단한 학습용 앱에서는 테이블 하나와 상태 하나로 끝나는 단순함을 택했다.

## Consequences

- 덮어쓴 평점과 감상평은 되살릴 수 없다. 나중에 재독 이력이 필요해지면 구조를 바꾸는 것은 물론이고, 그 전까지의 이력은 이미 남아 있지 않다.
- 재독을 시작해 다 읽음에서 읽는 중으로 되돌려도 평점과 감상평은 다시 다 읽음으로 바꿀 때까지 그대로 남는다.
